## What it enables

- Receive production alerts with context
- Approve or reject agent actions with one click
- Ask Forge questions using slash commands
- Get weekly digest reports

## Setup

### 1. Create a Slack app

Go to [api.slack.com/apps](https://api.slack.com/apps) and create a new app **From scratch**.

### 2. Configure the app

Under **OAuth & Permissions**, add these bot token scopes:

```
chat:write
commands
incoming-webhook
```

Under **Incoming Webhooks**, enable and create a webhook for your alerts channel.

Under **Slash Commands**, create:
```
/forge — Send commands to Forge
```

### 3. Add to environment

```bash
SLACK_BOT_TOKEN=xoxb-your-bot-token
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/...
SLACK_CHANNEL=#forge-alerts
```

### 4. Set request URL for slash commands

```
https://your-forge-domain.com/webhooks/slack
```

## Slash commands

| Command | Description |
|---|---|
| `/forge status` | Show health score and recent activity |
| `/forge incidents` | List open incidents |
| `/forge approve <id>` | Approve a pending action |
| `/forge reject <id>` | Reject a pending action |
| `/forge build <description>` | Queue a feature request |
| `/forge deploy` | Trigger a production deployment |
