---
title: Fixer Agent
description: Performs root-cause analysis on incidents and generates code patches to resolve them.
---

## What it does

The Fixer agent is triggered when Watcher detects an incident. It:

1. Loads the relevant code context from `CodebaseContext`
2. Sends the incident details + code to Claude for root-cause analysis
3. Generates a targeted code patch
4. Opens a GitHub PR with the fix
5. Requests approval (in `SEMI` mode) or auto-merges (in `FULL` mode)

## Root-cause analysis

Fixer uses Claude to reason about the incident:

```
Given this incident:
  - Error: "TypeError: Cannot read properties of undefined (reading 'id')"
  - File: src/app/api/auth/route.ts
  - Frequency: 47 errors in the last 10 minutes

And this code context:
  [relevant file contents]

Identify the root cause and provide a minimal, targeted fix.
Output as JSON: { rootCause, explanation, patch, affectedFiles }
```

Claude's structured response is validated against a Zod schema before any action is taken.

## Patch generation

Fixer generates **minimal patches** — the smallest change that resolves the issue. It avoids:
- Refactoring unrelated code
- Changing test files unless the bug is in a test
- Modifying dependencies

## GitHub PR format

```markdown
## Bug Fix: [incident title]

### Root Cause
[Plain-English explanation for the founder]

### What Changed
- `src/app/api/auth/route.ts` — Added null check before accessing user.id

### Testing
- [ ] Verified the error no longer reproduces locally
- [ ] Existing tests pass

Fixes #[incident-id]

🤖 Auto-generated by Forge Fixer Agent
```

## Approval flow

In `SEMI` autonomy mode:

```
Fixer creates PR → ApprovalRequest created
                          │
              ┌───────────┴───────────┐
              │                       │
         [Approve]               [Reject]
              │                       │
    PR merges + deploys      PR closed, incident
                              stays OPEN for manual fix
```

## Configuration

```bash
# Enable/disable auto-merge in FULL mode
FIXER_AUTO_MERGE=true

# Max files a fix can touch (safety limit)
FIXER_MAX_FILES=5

# Skip fixer for these file patterns (too risky)
FIXER_SKIP_PATTERNS=prisma/migrations/**,package.json
```
